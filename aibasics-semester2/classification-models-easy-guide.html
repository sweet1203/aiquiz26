“모델”은 문제를 푸는 방법이에요.
아래 4가지는 모두 예 / 아니오처럼 종류를 맞히는 데 씁니다.

① k-NN ② 로지스틱 회귀 ③ 서포트 벡터 머신 ④ 의사결정트리 ⑤ 한눈에 비교

먼저, 모델이 뭐야?

시험 공부를 예로 들어요. 과거에 풀었던 문제(훈련 데이터)를 보고 “비슷한 문제가 나오면 이렇게 풀자”는 규칙을 만드는 것이 모델입니다.

키, 몸무게, 공부 시간…
→ 단서들

출력(종속 변수)
합격 / 불합격
→ 맞히고 싶은 것
k

k-NN

k-Nearest Neighbors · 케이 엔엔 · “가까운 이웃”

🙋 “주변 친구들이 뭐라고 하니?” → 다수결로 정해요

새 친구가 전학 왔어요. 이 친구가 축구파인지 농구파인지 모를 때, 제일 가까운 친구 k명에게 물어보고 더 많은 쪽으로 정합니다.

  • k = 3이면 가까운 3명에게 물어봄
  • 축구 2 · 농구 1 → 축구파로 분류
  • “거리”가 가까울수록 더 비슷한 데이터
기억! 키·몸무게처럼 숫자 크기가 다르면 “키 1cm”와 “몸무게 1kg”가 불공평해져요 → 그래서 표준화를 자주 해요.

점선 원 안이 “가까운 이웃”이에요

%

로지스틱 회귀

Logistic Regression · “확률로 나누기”

📊 “합격 확률이 50%보다 크면 합격!” 처럼 선을 그어요

이름은 “회귀”지만, 우리가 쓰는 건 두 갈래로 나누는 분류예요.
공부 시간이 늘수록 합격 확률이 올라간다고 보고, 부드러운 S자 곡선으로 “얼마나 확실한지(%)”를 계산합니다.

  • 출력은 대략 0~100% 확률
  • 보통 50% 넘으면 A반, 아니면 B반
  • “왜 그렇게 나왔는지”를 숫자(가중치)로 설명하기 쉬움
비유: 온도계처럼 “조금 위험한지 / 많이 위험한지”를 확률로 보여 주는 모델이에요.

S자 곡선: 왼쪽은 낮고, 오른쪽으로 갈수록 확률이 올라가요

‖

서포트 벡터 머신

SVM · Support Vector Machine · “가장 넓은 길 찾기”

🛣️ 두 무리 사이에 가장 넓은 안전 통로를 만들어요

교실 바닥에 파란 팀·주황 팀이 서 있어요. 선생님은 두 팀 사이에 선을 그어 나누는데, 선을 너무 한쪽에 붙이면 위험하겠죠?

SVM은 양쪽에서 가장 가까운 친구들(서포트 벡터)을 보고, 그 사이 여유(마진)가 제일 넓은 경계를 고릅니다.

  • “딱 붙어 나누기”보다 여유 있게 나누기
  • 경계 근처의 몇 점이 특히 중요
  • 데이터가 복잡하면 곡선 경계도 가능(고급)
비유: 두 나라 사이에 비무장지대처럼 넓은 중간 지대를 남기는 국경선이에요.

검은 테두리 점 = 경계를 정하는 데 중요한 “서포트 벡터”

◇

의사결정트리

Decision Tree · “스무고개 · 질문 나무”

🌳 “질문이 맞으면 왼쪽, 아니면 오른쪽!” 스무고개처럼 분류해요

친구에게 동물을 맞히게 할 때처럼, 예/아니오로 대답할 수 있는 질문을 이어 갑니다.

  • 나이 > 50? → 예 / 아니오
  • 콜레스테롤이 높은가? → 예 / 아니오
  • 끝까지 가면 결과(발병 / 정상)가 나옴

사람이 읽기 쉬운 장점이 커요. “왜 이 환자를 위험하다고 했지?”를 질문 경로로 설명할 수 있습니다.

주의: 질문을 너무 잘게 나누면 훈련 데이터만 외워 버리는 과대적합이 잘 생겨요. (그래서 max_depth로 깊이를 제한하기도 합니다.)

위 = 질문, 아래 색 상자 = 최종 답

한눈에 비교하기

어떤 걸 고를지 고민될 때 이 표를 보세요.

모델 한 줄 비유 잘 맞는 때 조심할 점
k-NN 가까운 친구에게 물어보기 데이터가 비슷한 것끼리 모여 있을 때 숫자 단위가 다르면 표준화 필요 · 느려질 수 있음
로지스틱 회귀 확률(%)로 선 긋기 예/아니오 + “얼마나 확실한지”가 필요할 때 관계가 너무 복잡하면 힘듦
SVM 가장 넓은 안전 통로 두 무리가 비교적 나뉘어 보일 때 개념이 어려움 · 설정을 잘 맞춰야 함
의사결정트리 스무고개 질문 나무 이유를 사람 말로 설명하고 싶을 때 너무 깊게 나누면 과대적합

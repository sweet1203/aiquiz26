5개의 알고리즘을 만나러 가는
작은 지도 🧭

지난 시간에 풀어본 문제들이 각각 어떤 알고리즘으로 연결되는지, 왜 그 알고리즘이어야 하는지 하나씩 짚어볼게요. 어려운 수식은 잠시 접어두고, 그림으로 먼저 느낌을 잡아봅시다.

먼저, 큰 그림부터

지도학습일까, 비지도학습일까?

다섯 알고리즘을 나누는 가장 큰 기준이에요. "정답을 미리 알려주고 배우는가, 아니면 정답 없이 스스로 규칙을 찾는가" — 이 질문 하나로 절반은 구분할 수 있어요.

지도학습 (Supervised)

정답지를 보면서 공부해요

이렇게 "특징 + 정답"이 짝지어진 데이터로 배운 다음, 정답이 없는 새 데이터의 정답을 맞혀요. ①③④⑤번이 여기에 속해요.

비지도학습 (Unsupervised)

정답 없이 스스로 무리를 지어요

정답표 없이 "비슷한 것끼리" 스스로 묶어요. 사람이 미리 정답을 주지 않는다는 게 핵심! ②번이 여기에 속해요.

① 문제: 어떤 종류의 펭귄인지 분류하기

k-최근접 이웃 (k-Nearest Neighbors)

지도학습 분류(Classification)
쉬운 비유 전학 온 첫날, 급식실에서 누구랑 앉을지 모를 때 가장 가까이 앉은 친구들을 보고 "아, 이 무리구나" 하고 판단하는 것과 같아요. kNN도 새로운 데이터가 들어오면 가장 가까운 k개의 이웃을 찾아, 그중 다수결로 정답을 정해요.

k=3이면 가장 가까운 3개를 보고, 2개가 "아델리"라면 새 데이터도 아델리로 분류해요. k를 얼마로 정하느냐에 따라 결과가 달라질 수 있어요.

  • 부리 길이·몸무게로 펭귄 종류 분류하기
  • 키·몸무게로 운동복 사이즈 추천하기
  • 좋아하는 노래 장르로 비슷한 취향의 친구 찾기
물음표 주변에서 가장 가까운 3마리 중 2마리가 아델리 → 새 펭귄도 "아델리"로 예측!
# 라이브러리
from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)
② 문제: 데이터 분석 과제 모둠을 구성하기

k-평균 (K-Means)

비지도학습 군집화(Clustering)
쉬운 비유 체육 시간에 선생님이 "키랑 운동 실력 보고 비슷한 사람끼리 알아서 3팀으로 모여봐!"라고 하는 것과 같아요. 누가 어느 팀인지 정해주지 않아도, 가까이 있는 사람끼리 자연스럽게 모이죠. k-평균은 중심점(centroid)을 옮겨가며 가장 가까운 데이터끼리 묶어요.

k=3이면 3개의 무리로 나눠요. 정답 라벨이 없다는 점이 kNN과 결정적으로 다른 부분이에요 — 이름은 비슷해도 완전히 다른 학습 방식이에요!

  • 수학 점수·코딩 흥미도로 비슷한 성향의 모둠 구성하기
  • 구매 패턴으로 고객 유형 나누기 (쇼핑몰 추천)
  • 사진 속 색상으로 비슷한 색끼리 묶어 대표 색 뽑기
×표시는 각 그룹의 중심(centroid). 가까운 학생끼리 저절로 3개 그룹으로 묶여요.
# 라이브러리
from sklearn.cluster import KMeans
model = KMeans(n_clusters=3)
model.fit(X)
③ 문제: 성적을 예측하기

선형 회귀 (Linear Regression)

지도학습 회귀(Regression)
쉬운 비유 지난 시험들의 "공부 시간 vs 점수"를 그래프에 콕콕 찍어보면 대충 오른쪽 위로 올라가는 흐름이 보여요. 그 점들 사이로 가장 잘 맞는 직선 하나를 그으면, 공부 시간만 알아도 대략적인 점수를 예측할 수 있어요.

"몇 반이냐" 같은 분류가 아니라 "몇 점이냐"처럼 이어지는 숫자를 예측한다는 게 핵심이에요. 그래서 회귀(Regression)예요.

  • 공부 시간으로 다음 시험 점수 예측하기
  • 기온으로 아이스크림 판매량 예측하기
  • 운동 시간으로 소모 칼로리 예측하기
점들 사이로 그은 직선 위에서 "4시간 공부하면 몇 점?"을 바로 읽을 수 있어요.
# 라이브러리
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)
④ 문제: 트리 구조를 사용하여 분류하기

의사결정트리 (Decision Tree)

지도학습 분류(Classification)
쉬운 비유 "스무고개" 놀이와 똑같아요. 예/아니오로 답할 수 있는 질문을 계속 던지면서 점점 답을 좁혀가요. "코딩을 좋아해?" → "논리적으로 푸는 게 재밌어?" → 결론에 도착!

질문 하나하나가 가지(branch)가 되고, 마지막 결론이 잎(leaf)이 돼요. 사람이 판단하는 순서를 그대로 흉내 낸 알고리즘이라 결과를 설명하기 쉬운 게 장점이에요.

  • 날개 유무·비행 가능 여부로 동물 종류 분류하기
  • 증상 체크리스트로 질병 여부 1차 진단하기
  • 스팸 메일 특징으로 스팸 / 정상 분류하기
예/아니오 질문을 따라 내려가면 마지막 상자(잎)에서 결론이 나와요.
# 라이브러리
from sklearn.tree import DecisionTreeClassifier
model = DecisionTreeClassifier()
model.fit(X_train, y_train)
⑤ 문제: 심장마비가 발생할지 아닐지 구분하기

로지스틱 회귀 (Logistic Regression)

지도학습 분류(이진 분류)
쉬운 비유 이름에 "회귀"가 들어가지만, 사실 하는 일은 "둘 중 하나를 고르는 분류"예요! 위험 요인 점수가 낮으면 0(안전)에, 높으면 1(위험)에 가까운 확률(0~100%)을 계산한 다음, 50%를 기준으로 "위험/안전"을 딱 잘라 결정해요.

선형 회귀의 직선과 달리, 값이 0과 1 사이로만 나오도록 S자 곡선을 사용해요. "몇 %의 확률로 그럴까?"를 다룰 때 딱 맞는 알고리즘이에요.

  • 건강 지표로 심장마비 발생 여부 예측하기
  • 이메일 특징으로 스팸 여부 판단하기
  • 문제 풀이 패턴으로 합격/불합격 예측하기
S자 곡선이 기준선(50%)을 넘으면 "위험", 못 넘으면 "안전"으로 분류해요.
# 라이브러리
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X_train, y_train)
마무리

다섯 알고리즘, 한눈에 정리

알고리즘학습 방식문제 유형대표 문제라이브러리
k-최근접 이웃지도학습분류펭귄 종류 분류KNeighborsClassifier()
k-평균비지도학습군집화모둠 구성KMeans
선형 회귀지도학습회귀성적 예측LinearRegression()
의사결정트리지도학습분류트리 구조 분류DecisionTreeClassifier()
로지스틱 회귀지도학습분류(이진)심장마비 여부 판단LogisticRegression()
kNN vs k-평균 — 이름이 비슷해서 가장 헷갈려요. kNN은 정답이 있는 지도학습(분류), k-평균은 정답이 없는 비지도학습(군집화)이에요.
회귀 vs 분류 — "숫자 몇 점?"처럼 연속된 값을 예측하면 회귀, "A반이냐 B반이냐"처럼 몇 개의 종류 중 하나를 고르면 분류예요.
로지스틱 회귀는 이름 함정 — "회귀"라는 이름이지만 실제로는 분류 알고리즘이에요. 확률을 계산해서 둘 중 하나로 나누기 때문이에요.

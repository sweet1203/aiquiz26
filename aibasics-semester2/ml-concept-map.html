Ⅱ. 인공지능과 학습 · 단원 도입

모델? 알고리즘? 학습 방식?
헷갈리는 3개념 한 번에 정리 🗺️

이 셋은 서로 다른 층위예요. 학습 방식은 큰 분류, 알고리즘은 배우는 방법, 모델은 배운 결과물. 이 페이지 내내 보라=학습방식 · 파랑=알고리즘 · 초록=모델 색을 고정해서 씁니다.

가장 큰 그림부터

한 줄로 보는 관계

학습 방식을 정하고 → 그 안에서 알고리즘을 고르고 → 데이터로 학습시키면 → 모델이 완성돼요.

각 단어의 정체

세 단어, 한 줄 정의

보라 · 큰 분류

학습 방식

무엇을 보고 배우나 — 정답(라벨)이 있으면 지도학습, 없으면 비지도학습.

예: 지도학습 · 비지도학습 · 강화학습

파랑 · 방법

알고리즘

어떻게 배우나 — 학습하는 절차·방법. 요리의 레시피에 해당해요.

예: kNN · 결정트리 · 선형회귀 · 로지스틱회귀 · K-평균

초록 · 결과물

모델

배운 결과물 — 알고리즘이 데이터로 학습을 끝낸 뒤 나온, 예측하는 완제품.

예: 펭귄 분류 모델 · 성적 예측 모델

가장 헷갈리는 둘 — 알고리즘 ≠ 모델

🍳 요리로 이해하기

쉬운 비유 알고리즘은 레시피(종이에 적힌 방법)예요. 여기에 데이터라는 재료를 넣고 학습(요리)을 하면, 모델이라는 완성된 요리가 나와요. 레시피만으로는 먹을 수 없듯, 알고리즘만으로는 예측을 못 해요. 데이터로 학습을 끝내야 모델이 됩니다.
🔑 핵심: 같은 레시피(알고리즘)라도 재료(데이터)가 다르면 다른 요리(모델)가 나와요.
→ kNN + 펭귄 데이터 = 펭귄 분류 모델 / kNN + 붓꽃 데이터 = 붓꽃 분류 모델
레시피 + 재료 → 요리 → 완성. 모델은 "학습을 끝낸 결과"예요.
학습 방식을 가르는 기준

지도학습 vs 비지도학습 — 정답이 있나?

가장 큰 갈림길은 딱 하나예요: 데이터에 정답(라벨)이 붙어 있는가?

지도학습 (정답 O)

정답지를 보며 배워요

분류(갈래 맞히기)와 회귀(숫자 맞히기)가 여기 속해요. 예: kNN·결정트리·선형회귀·로지스틱회귀.

비지도학습 (정답 X)

정답 없이 스스로 묶어요

군집(비슷한 것끼리 묶기)이 대표예요. 사람이 정답을 안 줘도 스스로 무리를 찾아요. 예: K-평균.

자주 하는 오해 3가지

❌ "모델이랑 알고리즘이 같은 말 아니에요?"
→ 달라요. 알고리즘은 배우는 방법, 모델은 학습을 끝낸 결과물. 레시피(방법)와 완성된 요리(결과)의 차이예요.
❌ "지도학습도 알고리즘 이름 아니에요?"
→ 아니에요. 지도/비지도는 정답 유무로 나눈 큰 분류이고, 그 안에 kNN·결정트리 같은 구체적 알고리즘이 들어 있어요.
❌ "로지스틱 회귀니까 숫자를 예측하는 회귀죠?"
→ 이름만 회귀예요. 실제로는 확률을 계산해 둘 중 하나로 나누는 분류 알고리즘입니다.

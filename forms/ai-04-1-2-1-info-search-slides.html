1-2-1 탐색을 활용한 문제 해결

정보이용 탐색 알고리즘

무작정 모든 길을 가 보는 대신, “목표에 가까워 보이는가?”라는 힌트를 사용해 더 똑똑하게 탐색하는 방법을 배웁니다.

목표 1맹목적 탐색과 정보이용 탐색의 차이를 설명한다.
목표 2언덕 등반, 최상 우선, A*의 선택 기준을 비교한다.
목표 3같은 문제에서도 알고리즘에 따라 경로가 달라질 수 있음을 이해한다.

큰 그림

탐색은 “가능한 길 중 하나를 고르는 일”

미로에서 출구 찾기, 지도에서 빠른 길 찾기, 8-퍼즐 맞추기처럼 여러 선택지 중 하나를 골라 목표에 도착하는 과정입니다.

맹목적 탐색 목표에 가까운지 잘 모른 채 정해진 규칙대로 차례차례 확인합니다. 깊이 우선 탐색, 너비 우선 탐색이 여기에 속합니다.
정보이용 탐색 목표에 가까워 보이는 정도를 계산해 가능성이 높은 선택지를 먼저 봅니다. 이때 힌트를 휴리스틱 또는 평가 함수라고 합니다.
핵심: 정보이용 탐색은 “모든 곳을 다 보자”가 아니라 “목표에 가까워 보이는 곳부터 보자”는 전략입니다.
03 / 08

공통 핵심

평가 함수와 휴리스틱

정보이용 탐색은 선택지마다 점수를 매깁니다. 중요한 점은 평가 함수가 항상 “큰 값이 좋다”는 뜻은 아니라는 것입니다.

큰 값이 유리한 경우 점수가 높을수록 목표에 가까운 상황입니다. 예를 들어 8-퍼즐에서 제 위치에 놓인 조각 수는 많을수록 좋습니다.
작은 값이 유리한 경우 비용, 거리, 시간처럼 적을수록 좋은 상황입니다. 지도에서 목표까지 걸릴 예상 시간은 짧을수록 좋습니다.
쉬운 비유시험 공부 시간이 부족할 때 모든 문제를 똑같이 보지 않고, 시험에 잘 나오는 단원부터 보는 것과 비슷합니다.
생각 질문“목표에 가까워 보인다”는 판단이 항상 맞을까요? 틀리면 어떤 일이 생길까요?
오해 주의평가값을 볼 때는 먼저 “큰 값이 좋은가, 작은 값이 좋은가?”를 확인해야 합니다.

알고리즘 1

언덕 등반 탐색

현재 위치에서 주변을 보고, 지금보다 더 좋아지는 곳이 있으면 그쪽으로 이동합니다. 교과서 예시는 8-퍼즐이며, 평가값은 제 위치에 놓인 조각 수입니다.

현재 상태의 점수를 계산한다.
갈 수 있는 다음 상태들의 점수를 계산한다.
현재보다 점수가 높은 상태로 이동한다.
더 좋아지는 상태가 없으면 멈춘다.
비유안개 낀 산에서 바로 옆보다 높은 곳으로만 계속 올라가는 방법입니다.
생각 질문주변이 모두 낮아 보이면, 진짜 산 정상에 도착한 걸까요?
한계전체에서 가장 좋은 답이 아닌데 멈출 수 있습니다. 이것을 지역 최적이라고 합니다.
05 / 08
알고리즘 2

최상 우선 탐색

지금 보이는 후보들 중 평가값이 가장 좋은 것을 먼저 선택합니다. 언덕 등반과 달리 선택하지 않은 후보도 버리지 않고 다시 고려할 수 있습니다.

f(C) = 목표까지 예측 시간

부산에서 서울까지 가는 교과서 예시에서는 목표까지의 예측 시간을 보고 다음 경로를 선택합니다.

부산→상주→음성→서울
생각 질문서울과 가까워 보이지만 실제 도로가 오래 걸린다면 어떻게 될까요?
오해 주의“좋아 보임”은 실제 이동 시간까지 모두 계산했다는 뜻이 아닐 수 있습니다.

알고리즘 3

A* 알고리즘

A*는 “목표까지 가까워 보이는가?”뿐 아니라 “여기까지 오느라 이미 얼마나 비용을 썼는가?”도 함께 봅니다.

f(n) = g(n) + h(n)
g(n)출발점에서 현재 위치까지 실제로 사용한 비용입니다.
h(n)현재 위치에서 목표까지 앞으로 남은 비용을 예상한 값입니다.

같은 부산→서울 문제에서 A*는 실제 비용과 예측 비용을 함께 보므로 다른 경로를 선택합니다.

부산→대구→대전→천안→서울
최상 우선 탐색은 남은 비용을 주로 보고, A*는 지금까지의 실제 비용과 남은 예상 비용을 더해 봅니다.

정리

마무리 비교표

알고리즘 선택 기준 평가값 방향 교과서 예시 장점 주의할 점
언덕 등반 탐색 현재보다 평가값이 더 좋아지는 상태로만 이동 큰 값이 유리
제 위치 조각 수가 많을수록 좋음		 8-퍼즐: 제 위치에 놓인 조각 수 방법이 단순하고 빠르게 진행할 수 있음 지역 최적에 빠져 목표가 아닌 곳에서 멈출 수 있음
최상 우선 탐색 후보 중 목표에 가장 가까워 보이는 것을 먼저 선택 작은 값이 유리
목표까지 예측 시간이 짧을수록 좋음		 부산 → 상주 → 음성 → 서울 선택하지 않은 후보도 다시 고려할 수 있음 예측만 보고 고르면 실제 비용이 큰 길을 선택할 수 있음
A* 알고리즘 지금까지 실제 비용 g(n) + 남은 예상 비용 h(n) 작은 값이 유리
전체 예상 비용 f(n)이 작을수록 좋음		 부산 → 대구 → 대전 → 천안 → 서울 지나온 비용과 앞으로의 예측을 함께 보아 균형 있게 탐색함 평가값을 계산할 정보가 필요하며, h(n)의 품질이 중요함
한 줄 정리: 정보이용 탐색의 차이는 “무엇을 좋은 선택이라고 판단하는가”에서 나옵니다.

형성평가

객관식 문제

제출 버튼은 없습니다. 먼저 스스로 답을 골라 본 뒤, 각 문제의 “답 확인”을 열어 정답과 해설을 확인하세요.

1. 정보이용 탐색에서 평가 함수의 역할로 가장 알맞은 것은?
답 확인

정답: 2번. 평가 함수는 후보가 목표에 얼마나 가까워 보이는지 판단하는 기준입니다.

2. 언덕 등반 탐색이 목표가 아닌 곳에서 멈출 수 있는 이유는?
답 확인

정답: 1번. 주변보다 좋아 보여도 전체에서 가장 좋은 답은 아닐 수 있습니다. 이것을 지역 최적이라고 합니다.

3. 최상 우선 탐색에 대한 설명으로 알맞은 것은?
답 확인

정답: 2번. 최상 우선 탐색은 후보를 관리하면서 가장 좋아 보이는 것을 먼저 선택합니다.

4. A* 알고리즘의 식 f(n) = g(n) + h(n)에서 g(n)은 무엇인가?
답 확인

정답: 2번. g(n)은 지금까지 실제로 사용한 비용입니다. h(n)은 앞으로 남은 비용의 예상값입니다.

5. 같은 부산→서울 문제에서 최상 우선 탐색과 A*의 경로가 달라질 수 있는 까닭은?
답 확인

정답: 3번. A*는 g(n)과 h(n)을 함께 고려하므로, 남은 거리만 보는 방식과 다른 선택을 할 수 있습니다.

6. 평가 함수에 대한 설명으로 가장 알맞은 것은?
답 확인

정답: 3번. 퍼즐의 맞은 조각 수처럼 큰 값이 좋은 경우도 있고, 시간·거리·비용처럼 작은 값이 좋은 경우도 있습니다.

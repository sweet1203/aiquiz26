📌 30초 정리 — 정확도·정밀도·재현율

예시 하나로 감을 잡고 아래 질문에 답해요. 스팸 분류 — 실제 스팸 10개, 정상 90개일 때

모델: 스팸 👎
모델: 정상 👍
진짜 스팸
TP 6
맞게 잡음
FN 4
놓침 😵
진짜 정상
FP 2
헛알람 😅
TN 88
잘 통과

TP=제대로 잡음 · FP=아닌데 잡음(헛알람) · FN=맞는데 놓침 · TN=제대로 통과

✔ 정확도 (Accuracy) — "얼마나 자주 맞히나"

전체 100개 중 맞게 판정한 비율.

(TP+TN) / 전체 = (6+88)/100 = 0.94

⚠ 스팸이 원래 드물면, 전부 "정상"이라 찍어도 정확도가 높게 나와요 → 정확도만 믿으면 안 됨.

🎯 정밀도 (Precision) — "찍은 게 진짜일 확률"

모델이 "스팸!"이라 한 것 중 진짜 스팸 비율.

TP / (TP+FP) = 6/8 = 0.75

→ 낮으면 헛알람(FP)이 많다는 뜻. 잘못 잡으면 곤란할 때 중요.

🔍 재현율 (Recall) — "놓치지 않는 능력"

진짜 스팸 중 모델이 잡아낸 비율.

TP / (TP+FN) = 6/10 = 0.60

→ 낮으면 놓침(FN)이 많다는 뜻. 놓치면 큰일 날 때 중요.

🩺 질병 진단 → 재현율 중요
환자를 "정상"이라 놓치면(FN) 치료를 못 받아 위험. 조금 과하게 잡더라도 놓치면 안 됨.
📧 스팸 분류 → 정밀도 중요
중요한 정상 메일을 스팸으로 잘못 버리면(FP) 손해. 확실할 때만 스팸 처리.
